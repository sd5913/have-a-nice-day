# Little Cat Chef

Pick ingredients from eight trays, follow the cat’s order and quantities, stir the bowl, and call the cat to taste the meal. A correct meal earns **Bond +1**. Incorrect meals never reduce bond. New orders and R (retry) keep the accumulated bond during this session.

## Setup and run

From the repository root, use Python 3.11 and the shared dependencies:

```sh
uv venv --python 3.11
uv pip install -r requirements-shared.txt
uv run --no-project python -m games.little_chef.demo
```

Mouse mode works without a camera or model file. For hand controls, download the official model first:

```sh
uv run --no-project python download_model.py
uv run --no-project python -m games.little_chef.demo --hand
```

Allow camera access if prompted. Choose another camera with `--camera 1`. See ../../SHARED_INPUT.md for shared input setup.

## Play

1. Read the order at the top, including quantities. Hold the left mouse button over a tray, drag to the bowl, then release. The tray replenishes for repeat portions.
2. Backspace removes the last portion before mixing. Add at least two portions and click MIX INGREDIENTS.
3. Hold the left button and follow the dotted guide around the bowl in one direction for two turns. Release to rest; mixing progress is retained.
4. Click CALL CAT. The cat approaches and eats, even after your hand leaves the camera.
5. Read the reaction and click NEW ORDER to play again. Exact ingredients and portions earn one bond point, once per order.

H switches to hand input, M to mouse, R retries the current order, Enter activates the current action button, Q/Esc exits. Window close also exits. With camera input, first open your hand once, then pinch to drag and release to drop. In mixing mode hold fingers together and circle along the guide. You can still click action buttons with the mouse in camera mode. Missing camera/model shows a setup error and keeps mouse mode available. Lost tracking cancels a held ingredient and returns it safely.

## Code and artwork

- game.py: orders, quantities, stirring, reactions and session bond.
- view.py: layout and rendering.
- demo.py: standalone game input loop using the shared utils input modules.
- visuals.py: optional PNG loading and code-drawn placeholder artwork, isolated here to avoid changing other games’ graphics.

An optional assets/ folder next to demo.py can contain background.png, cat.png, bowl.png and ingredient_fish/chicken/kibble/pumpkin/carrot/peas/rice/salmon.png. Transparent PNGs work for sprites; missing images use built-in drawings. No image downloads are required.

## Validation and limitations

```sh
uv run --no-project python -m unittest discover -s tests -v
```

Chef tests cover the full cooking/replay loop, tracking loss, incorrect meals, portion counts, undo and bond being awarded only once. Automated tests run locally; fresh-machine camera setup and the latest stirring gesture still need a teammate playtest. The student previously confirmed pinch dragging works.

Placeholder art only; final kitchen art and sound are pending. Bond is held in memory, resets when the program closes, and is not yet shared across the four games. Orders rotate through preset recipes rather than following the real calendar. Recipe rules are fictional gameplay, not cat nutrition advice.

Implemented by Li Xinyang with Codex assistance for coding, debugging and automated tests. Uses the team’s shared MediaPipe input module, originally based on Cshushs1’s GestureTracker. Placeholder graphics are generated by drawing code; no borrowed game artwork is bundled.
